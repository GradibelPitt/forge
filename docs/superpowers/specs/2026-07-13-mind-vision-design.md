# 心灵视界设计规格

## 牌面

- 名称：心灵视界
- 法术力费用：{U}
- 类别：法术
- 稀有度：普通
- 规则叙述：检视目标对手的手牌，从中选择一张牌。化生一张以此法选择的牌名的复制并置于你的手上。它减少{1}来施放。

“选择一张牌”包括地牌。若选择地牌，仍会正常化生该牌，但减少咒语费用通常没有实际作用。

## 规则实现

使用当前 Forge 已有的纯卡牌脚本能力链，不新增 Java API：

1. 以一位对手为目标，并仅向心灵视界的操控者展示该对手的手牌。
2. 从该目标对手当时的手牌中强制选择一张牌，不限制牌张类别。
3. 读取所选牌的印刷牌名，化生一张该牌名对应的全新牌张到心灵视界操控者的手牌。化生牌不继承被选中游戏对象上的指示物、持续效应或永久修改。
4. 对刚化生的牌施加永久静止异能，使该牌作为咒语施放时减少{1}来施放。此效果只减少通用费用，不移除有色、无色或其他特定费用要求。
5. 结算结束时清理脚本用于保存所选牌与化生牌的临时引用。

首选能力组合为 `RevealHand`、`ChooseCard`、`MakeCard` 与具有 `Duration$ Perpetual` 的 `Animate`。这与 Forge 当前官方脚本中的隐藏手牌检视、按所选牌名化生及永久获得静止异能的模式一致。

## 边界行为

- 目标对手的手牌为空时，心灵视界只完成检视，不化生牌。
- 若目标在结算时已不再合法，则依照正常目标规则处理，不能从其他玩家手牌改选。
- 若所选牌是双面牌或其他具有特殊牌面的牌，化生结果由 Forge 按其印刷牌名载入完整牌张定义。
- 永久减费跟随化生出的具体牌张跨区域保留，但不会使该牌获得免费施放权限，也不会改变地牌的打出规则。

## 验证

- 契约测试确认名称、{U} 费用、法术类别、普通稀有度与 PH01 唯一登记。
- 脚本契约确认能力链以目标对手为对象、允许选择任意手牌、按所选牌名化生到你的手牌，并只对化生牌施加永久减少{1}的效果。
- 边界测试覆盖空手牌、选择地牌、选择非地牌及临时引用清理。
- 运行单卡 lint、相关目标测试和 DIY 全量测试。
- 运行安装脚本后，对比源脚本、源图片与 Forge 部署副本的 SHA-256。
- 客户端重启或重载资源后，手工确认仅施法者可检视手牌、选择界面正确、化生牌位于手牌且费用显示减少{1}。
