# 异教低阶牧师设计规格

## 牌面

- 名称：异教低阶牧师
- 法术力费用：{U}{B}
- 类别：生物～人类／牧师
- 稀有度：稀有
- 力量／防御力：3/2
- 规则叙述：对手施放的瞬间和法术咒语增加{1}来施放。

## 规则实现

使用 Forge 现有的 `RaiseCost` 静止异能，并把施放者限制为 `Opponent`、牌张限制为瞬间或法术。异能只从战场生效；异教低阶牧师离开战场后费用增加立即消失。每个在战场上的副本提供一份独立费用增加，因此多个副本自然叠加。

## 图片与本地化

将 `C:\Users\Marsh\Desktop\Cult_Neophyte_full.jpg` 作为原画来源，按现有纯原画流程裁剪至 Forge 插画区域并生成带游戏牌框的卡图。保留源图备份。向 `cardnames-zh-CN.txt` 添加中文名称和上述中文规则叙述。
