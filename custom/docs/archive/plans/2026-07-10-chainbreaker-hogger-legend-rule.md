# Chainbreaker Hogger Legend Rule Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make 破链灾星霍格 grant its controller a permanent, game-start Command-zone emblem that bypasses the legend rule for that controller's permanents.

**Architecture:** Keep the existing static `NewGame` trigger active from the initial Library or Hand. Extend its existing copy sub-ability chain with one `DB$ Effect` that creates a permanent emblem in Command; the effect owns the sole `IgnoreLegendRule` static ability. The player-scoped `ValidCard$ Permanent.YouCtrl` filter makes the existing Forge legend-rule bypass apply only to that player.

**Tech Stack:** Forge card-script DSL, Python standard-library `unittest`, Forge DIY linter, PowerShell sync script.
