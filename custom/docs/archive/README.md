## Archive rules

- 不在归档文件中更新当前状态。
- 新主文档链接到归档时，应注明其历史性质。
- 需要旧命令、测试输出或设计理由时，按主题读取单个文件，不批量加载整个归档。
- 如果归档与当前源码冲突，以当前用户需求、源码、测试和主文档为准。
