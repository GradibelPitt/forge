# 维希度斯的窟穴设计规格

## 卡牌定义

- 内部名称与中文显示名：`维希度斯的窟穴`
- 类型：地
- 版本：PH01
- 收藏编号：37
- 稀有度：稀有
- 规则文字：`{T}，弃一张牌：抽两张牌。`

## 规则语义

异能的起动费用为横置维希度斯的窟穴并由其操控者从自己手牌中选择弃一张牌。抽两张牌是异能的结算效果。没有手牌时不能起动此异能；异能被反击时，已经支付的横置与弃牌费用不会退回。

## Forge 实现

使用现有原生 DSL：

```text
A:AB$ Draw | Cost$ T Discard<1/Card> | NumCards$ 2 | Defined$ You | SpellDescription$ Draw two cards.
```

不修改 Java 引擎，不新增 DSL 参数。

## 卡图与本地化

用户附件是纯原画。原图备份到 `custom/tools/card-artwork/`，以确定性居中裁切生成约 1.37:1 的高质量 RGB JPEG：

```text
custom/cards/pictures/PH01/维希度斯的窟穴.artcrop.jpg
```

PH01 版本条目使用 `@Custom`，由 Forge 绘制地牌框。简体中文资源类型为“地”，规则文字逐字使用 `{T}，弃一张牌：抽两张牌。`。
