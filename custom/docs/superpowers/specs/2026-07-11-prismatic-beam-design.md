# 棱彩光束设计

`棱彩光束` 是费用 `{7}` 的无色瞬间。施放时指定一位对手；它对该对手以及该对手操控的每个生物和鹏洛客各造成 3 点伤害。该咒语减少的通用费用等于目标对手操控的生物与鹏洛客总数，最低可降至 `{0}`。

实现复用 Forge 现有 `DamageAll`、`ValidPlayers$ Targeted`、`Creature.TargetedPlayerCtrl,Planeswalker.TargetedPlayerCtrl` 与 ability-level `ReduceCost$ X`。原图是 1920×1401 的纯原画，比例已约为 1.37:1，直接转存为 RGB JPEG art crop，由 Forge 绘制标准牌框。
