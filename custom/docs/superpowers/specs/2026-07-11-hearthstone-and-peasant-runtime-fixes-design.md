# 炉石传说与农夫运行时修复设计

## 目标

修复三个已在客户端复现的问题：炉石传说徽记在先手第一次维持不产生法术力、最大手牌仍为 7、农夫位于手牌时仍触发。炉石传说产生的法术力必须跨步骤和阶段保留，但在当前回合结束时清空，不能跨回合。

## 根因与方案

农夫的 `Phase` 触发器没有限定 `TriggerZones$ Battlefield`，因此使用了触发器的宽泛默认区域。脚本直接补上战场区域限制。

Forge 的 `StaticAbility.getLayers()` 会因为 `AddKeyword` 把炉石规则能力放入 `ABILITIES` 层，但没有因为 `SetMaxHandSize` 再把它放入 `RULES` 层；结果疲劳关键词可被授予，最大手牌参数却从未执行。引擎将把 `SetMaxHandSize` 与 `RaiseMaxHandSize` 明确登记为规则层参数，并用 Java 回归测试覆盖混合静态能力。

炉石维持触发采用命令区徽记自身的法力指示物计数。测试必须从第一位牌手第一次维持开始，验证依次产生 1、2、3 点法术力。产生的法术力继续使用 Forge 的 `PersistentMana$ True`，并由现有回合结束清理路径清除；测试同时验证跨阶段保留与回合结束清空。

## 验证

- Python 契约测试验证两张卡的脚本区域与参数。
- Java 测试验证最大手牌静态能力分层。
- Java 游戏测试验证先手第一次维持、递增法力、跨阶段保留和回合结束清空。
- 构建桌面聚合 JAR，部署卡牌与 JAR 后进行客户端复测。
