# Forge DIY 一键 Windows 安装器设计

## 目标

生成一个面向零基础玩家的中文 Windows 安装 EXE。玩家双击后无需理解 Java、JAR、环境变量或 Forge 自定义目录即可完成安装，并通过桌面快捷方式启动包含当前 DIY 引擎规则、keywords、自定义卡牌、中文文本与自定义图片的 Forge。

## 安装包内容

- 当前源码重新构建的 `forge.exe` 与桌面聚合 JAR。
- Forge 桌面运行所需的基础资源与全部卡牌规则脚本。
- `custom/` 中实际部署所需的 PH01 版本、卡牌脚本、Token 脚本、自定义卡图与 Token 图片。
- 当前 `cardnames-zh-CN.txt`。
- 版本清单、文件大小与 SHA-256 清单。
- 私有 Java 17 运行时，作为系统没有合格 Java 时的离线回退。

安装包不包含 `%LOCALAPPDATA%/Forge/Cache/pics/cards` 中的官方卡图缓存。官方卡图仍由 Forge 按需自动下载；只携带 DIY 项目自己的卡图与 Token 图片。

## Java 策略

安装器检测 64 位 Java 17 或更高版本。若检测成功，启动器可以使用该 Java；若不存在、版本过低或无法运行，则使用安装目录内的私有 Java 17。私有运行时不写入系统 `PATH`，不替换系统 Java，不要求玩家手工配置，也不依赖安装时联网下载。

## 安装与升级

使用中文 Inno Setup 安装器，默认安装到用户可写目录，避免普通用户因管理员权限卡住。安装器创建桌面和开始菜单快捷方式，并提供标准卸载入口。

安装时只替换本包管理的 PH01 文件、DIY 卡牌脚本、DIY Token、DIY 图片和对应中文资源；不得删除玩家无关的牌组、偏好设置、对局记录或官方卡图缓存。重复运行同版本安装包应得到相同文件；运行新版安装包应覆盖旧版受管文件，避免残留旧脚本造成联机差异。

## 版本一致性

构建时生成唯一构建 ID 和 SHA-256 清单，覆盖聚合 JAR、启动器、运行所需资源、PH01、DIY 卡牌/Token 脚本、自定义图片与中文资源。安装结束后校验受管文件；启动前再次校验关键联机文件。若关键文件缺失或哈希不一致，启动器明确提示重新运行安装器，不直接进入游戏。

两位玩家安装同一个 EXE 且通过校验后，使用相同的引擎字节码、keywords、卡牌脚本和自定义资源。安装器不宣称能让不同安装包版本互相兼容。

## 产物与验证

最终产物包括单一安装 EXE、同目录 SHA-256 文件和简短版本说明。验证至少覆盖：

- 从干净目录静默构建桌面 JAR 与 `forge.exe`。
- DIY Python 全量测试、相关 Java 测试和卡牌 lint 通过。
- 安装包内不存在官方卡图缓存。
- 安装包内存在全部 DIY 图片和脚本。
- 在没有可用系统 Java 的模拟条件下能够使用私有 Java 启动。
- 安装后关键文件哈希与构建清单一致。
- 第二次安装不会产生重复或过期的受管 DIY 文件。
- 两个独立安装目录的联机关键清单完全一致。

客户端实际联机对战属于最终人工验收，不以自动化测试替代。
