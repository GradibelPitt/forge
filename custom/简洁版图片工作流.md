# Forge DIY 简洁版图片工作流

本流程用于绝大多数“用户提供一张原画，希望在 Forge 标准文字牌框中使用”的情况。它与 [图片导入流程.md](图片导入流程.md) 中的完整扩画流程并列；默认优先使用本流程。

## 适用范围

- 用户提供的是原画，不含最终牌框、费用、名称、类别、规则文字或 P/T。
- 需要 Forge 自己绘制标准文字牌框。
- 不需要 AI 扩画、Card Conjurer、中文文字排版或完整异画。

若用户提供的已经是完整成品牌，或明确要求完整扩画异画，改用 [图片导入流程.md](图片导入流程.md) 的相应分支。

完整且带有效果文字的成品牌必须直接用作游戏内 `.full.jpg`：先依照卡图实现效果并补全 `zh-CN` 资源，再原样复制卡图；不得裁切成插画、叠加 Forge 牌框或调用 Card Conjurer。

## 强制判定规则

在创建脚本、裁图或复制图片之前，必须先用图片查看工具实际打开用户提供的文件。图片类型只按实际可见内容判断，不能按文件名、扩展名、尺寸或路径判断；文件名中的 `_full`、`full-art`、`card` 等字样没有判定效力。

- 看不到最终牌名、费用、类别栏、规则文字、P/T 和完整牌框：视为纯原画，执行本简洁流程。
- 已经包含上述最终牌面元素：视为完整成品卡图，执行 `.full.jpg` 直通流程。
- 输入是纯原画，但用户明确要求完整扩画：才转入 Card Conjurer 流程。

图片处理分支不替代卡牌实现。必须同时按用户最终描述实现实际效果，并在 `forge-gui/res/languages/cardnames-zh-CN.txt` 中补全中文名称、类别和规则文字。用户后续修正描述时，脚本 Oracle、触发描述和 `zh-CN` 必须统一更新。

文字默认严格采用用户最终描述。只有明显错字可以纠正，或原句不符合规则模板时可以改为规范 wording；除此之外不得擅自润色、增删或改写。

## 输入与输出

| 内容 | 路径 / 规则 |
|---|---|
| 原图备份 | `tools/card-artwork/<原文件名>` |
| 游戏插画裁切图 | `cards/pictures/PH01/<卡名>.artcrop.jpg`（单画面） |
| 画面比例 | 横向约 `1.37:1` |
| 格式 | 高质量 RGB JPEG |
| 版本登记 | 首条 `PH01` 记录必须含 `@Custom` |

`<卡名>` 必须与卡牌脚本的 `Name:` 和 `Placeholder_Set.txt` 中的名称逐字一致。

## Agent 执行步骤

1. 实际打开图片并确认它是纯原画；不得根据文件名作此判断。
2. 确认或创建卡牌脚本、PH01 版本记录和所需的中文资源条目；脚本效果与中文描述采用用户最终措辞。
3. 把用户原图复制到 `tools/card-artwork/`；不得覆盖原图。
4. 裁剪原图为横向约 `1.37:1`。默认让人物或主体居中、略偏上；以面部、动作和关键道具完整可见为优先。只裁切与转码，不调用 AI 扩画或补全。
5. 单画面保存为 `cards/pictures/PH01/<卡名>.artcrop.jpg`，并确保 PH01 版本条目含 `@Custom`。只有版本表中存在同名的多画面记录时，才使用连续编号（如 `1.artcrop.jpg`、`2.artcrop.jpg`）。
6. 运行：

   ```powershell
   python tools\lint_card.py cards\<颜色>\<卡名>.txt
   powershell -ExecutionPolicy Bypass -File .\tools\install_to_forge.ps1
   ```

7. 对比源裁切图与缓存图的 SHA-256：

   ```powershell
   Get-FileHash `
     .\cards\pictures\PH01\<卡名>.artcrop.jpg, `
     "$env:LOCALAPPDATA\Forge\Cache\pics\cards\PH01\<卡名>.artcrop.jpg" `
     -Algorithm SHA256
   ```

8. 重启 Forge，或在开发者模式重新加载资源；确认标准文字牌框使用新插画，并核对名称、费用、类别、规则文字、P/T 与实际效果。

## 常见情况

- 裁切图是竖向：重新裁为横向约 `1.37:1`，不要把竖图直接作为 `.artcrop.jpg`。
- 游戏不显示图：确认版本条目含 `@Custom`，图片已由安装脚本同步，且 `UI_CARD_ART_FORMAT=Crop`。
- 主体被截断：保留原图，调整裁剪框后重新生成同名 `.artcrop.jpg` 并重新同步。
- 文件名含 `_full` 但图片没有牌框和文字：仍按纯原画处理；文件名不能覆盖实际图片内容。
